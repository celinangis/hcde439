Here's the code snippet:


// Include the library for capacitive touch sensing.
#include <CapacitiveSensor.h>

// Set up the capacitive sensor using pins 2 and 4.
CapacitiveSensor touchSensor = CapacitiveSensor(2, 4);

// Set the LED strip pin to 9.
const int stripPin = 9;

// Set the touch threshold.
long threshold = 2000;

// Run this function once.
void setup() {
  // Start serial communication.
  Serial.begin(9600);

  // Set pin 9 to LOW before it becomes an output.
  digitalWrite(stripPin, LOW);

  // Set pin 9 as an output, which starts LOW so the LED strip stays off.
  pinMode(stripPin, OUTPUT);

  // Make sure the LED strip starts off.
  analogWrite(stripPin, 0);
}

// Repeat this function continuously.
void loop() {
  // Read the capacitive touch sensor.
  long sensorValue = touchSensor.capacitiveSensor(30);

  // Print the sensor value.
  Serial.println(sensorValue);

  // Check whether the spoon is touched.
  if (sensorValue > threshold) {
    // Turn the LED strip on at full brightness.
    analogWrite(stripPin, 255);
  }
  // Run this when the spoon is not touched.
  else {
    // Turn the LED strip off.
    analogWrite(stripPin, 0);
  }

  // Wait 50 milliseconds before reading again.
  delay(50);
}

In setup, I made sure the LED strip stays off when the Arduino first turns on. Before pinMode() runs, pin 9 starts as an input, so it is not sending any signal to the MOSFET. I set pin 9 to LOW first, so when pinMode() makes it an output, it starts at 0 V instead of sending a signal by accident. The 10 kΩ pull-down resistor also keeps the gate at 0 V until I touch the spoon.

I chose a 1 MΩ resistor because it gives enough sensitivity to detect direct touch without making the sensor overly sensitive. For the output, I used an IRLZ44N N-MOSFET to control a 12 V LED strip. Pin 9 connects to the MOSFET's gate through a 220 Ω resistor, which limits the current coming out of the Arduino pin. I also added a 10 kΩ pull-down resistor between the gate and ground, which keeps the gate at 0 V when pin 9 is not sending a signal, so the LED strip does not turn on by accident. The positive side of the 12 V external power supply connects to the positive side of the LED strip, and the negative side of the strip connects to the MOSFET's drain. The MOSFET's source connects to ground, which is shared between the Arduino and the external power supply. When pin 9 sends 5 V, the gate gets about 4.9 V, the MOSFET turns on, and current flows from the drain to the source, turning the LED strip on. When pin 9 sends 0 V, the MOSFET turns off and the LED strip turns off. This way, the Arduino only controls the MOSFET, while the LED strip gets its power from the external 12 V supply.

Resistor Calculations

220 Ω Gate Resistor

I used a 220 Ω resistor between pin 9 and the MOSFET's gate to limit the current coming out of the Arduino pin. When pin 9 turns HIGH, the gate briefly draws current while it charges. Using Ohm's Law, the most this current can be is 5 V / 220 Ω = about 22.7 mA. After the gate is charged, it draws almost no current, so this only happens for a very short moment.

10 kΩ Pull-Down Resistor

I used a 10 kΩ pull-down resistor between the gate and ground to keep the MOSFET off when pin 9 is not sending a signal. When pin 9 is HIGH, a small steady current flows through both resistors (5 V / 10,220 Ω = about 0.5 mA). Because the two resistors split the voltage, the gate gets (5 V * 10,000 Ω / 10,220 Ω = about 4.89 V) instead of the full 5 V, which is still enough to turn the MOSFET on.

LED Strip and MOSFET Current

To find out how much current the LED strip uses, I measured it with a multimeter set to the 20 mA DC current range, and it read about 16 mA (0.016 A) when the strip was on. I placed the multimeter in series between the LED strip's negative wire and the MOSFET's drain, so all of the strip's current flowed through the meter. This is far below the IRLZ44N's 47 A maximum, so the MOSFET uses almost no power and stays cool. The LED strip itself uses about 12 V * 0.016 A = 0.19 W.

Expected Voltages

  • Pin 9: 0 V when OFF, 5 V when ON
  • MOSFET gate when ON: about 4.9 V
  • MOSFET source: 0 V (connected to ground)
  • MOSFET drain when ON: close to 0 V
  • MOSFET drain when OFF: about 12 V, since no current flows through the LED strip
  • Across the LED strip when ON: about 12 V
