// This is the pin where I am reading the thermistor voltage.
const int thermistorPin = A0;

// These are the PWM pins connected to my two LEDs.
const int blueLED = 9;
const int redLED = 10;

// This runs once when the Arduino starts.
void setup() {

  // Set the blue LED pin as an output.
  pinMode(blueLED, OUTPUT);

  // Set the red LED pin as an output.
  pinMode(redLED, OUTPUT);

  // Start the Serial Monitor so I can see the sensor values.
  Serial.begin(9600);
}

// This keeps running while the Arduino is on.
void loop() {

  // Read the voltage from the thermistor voltage divider.
  int sensorValue = analogRead(thermistorPin);

  // sensorValue range: 0 - 1023
  // LEDbrightness range: 0 - 255

  int brightness = map(sensorValue, 270, 300, 0, 255);
  brightness = constrain(brightness, 0, 255);

  // Keep the brightness value between 0 and 255.
  brightness = constrain(brightness, 0, 255);

  // Print a label before the thermistor reading.
  Serial.print("Thermistor reading: ");

  // Print the actual analog value.
  Serial.print(sensorValue);

  // Print a label before the PWM value.
  Serial.print(" | LED brightness: ");

  // Print the PWM brightness value.
  Serial.println(brightness);

  // If the reading is below the middle of my measured range, turn on the blue LED.
  if (sensorValue < 280) {

    // Make the blue LED brighter when the reading gets farther from the midpoint.
    analogWrite(blueLED, 255 - brightness);

    // Turn the red LED off.
    analogWrite(redLED, 0);
  }

  // If the sensor reading is 280 or higher, turn on the red LED.
else {

  // Turn the blue LED off.
  analogWrite(blueLED, 0);

  // Turn the red LED on using the mapped brightness.
  analogWrite(redLED, brightness);
}

  // Wait a little before taking another reading.
  delay(100);
}

Additional Questions

In your voltage divider, can the variable resistor be either R1 or R2 or does it need to be one or the other? Justify your answer with example calculations.

The thermistor can be used as either R1 or R2 in the voltage divider. The voltage at A0 is calculated using (V-out= 5 * R_2 / {R_1+R_2}). For example, if the fixed resistor is 10 kΩ and the thermistor is 5 kΩ, placing the thermistor at R2 gives (5 * 5 / 15 = 1.67V). If the thermistor is placed at R1 instead, the output becomes (5 * 10 / 15 = 3.33V). Both positions work, but switching the thermistor from R1 to R2 reverses how the output voltage changes as the thermistor resistance changes, so the code has to match the way the circuit is wired.

AnalogWrite and analogRead are respectively 8-bit and 10-bit values. Imagine you had 10-bit PWM and a 16-bit analog-to-digital converter instead. How would this change your map() code? Explain your answer.

If analogRead() used a 16-bit ADC, its range would change from 0-1023 to 0-65,535. If analogWrite() used 10-bit PWM, its range would change from 0 - 255 to 0 - 1023. Because of this, my map() code would change to map(sensorValue, 0, 65535, 0, 1023). The purpose of map() would stay the same, but the input and output ranges would be larger because the higher bit values provide more possible steps and more resolution.
